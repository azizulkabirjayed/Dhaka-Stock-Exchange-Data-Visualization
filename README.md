# About The Project
Scraped and analyzed real-time stock data from the DSE website. Calculated top gainers/losers, mapped trading codes to specific industry sectors, and visualized "Open vs. Close" price comparisons
<p align="right">(<a href="#readme-top">back to top</a>)</p>

# Data Collection Method
Automated BeautifulSoup scraping of real-time share prices and sectoral P/E data from the [DSE](https://www.dsebd.org/) website, including automated sanitization of non-numeric market symbols.
